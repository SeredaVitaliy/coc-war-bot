# CoC War Bot

Telegram-бот для клана в Clash of Clans. Следит за клановыми войнами и Лигой войн кланов (ЛВК) через официальный Clash of Clans API, напоминает игрокам об атаках и показывает, кто ещё не атаковал. Работает в группе клана (в том числе в отдельной теме) и в личных сообщениях.

## Что умеет

- **Война:** статус, время до начала и до конца, текущий счёт и список тех, кто не атаковал.
- **ЛВК:** статус раунда, прогресс, сравнение с соперниками, таблица группы, раунды и пропущенные атаки.
- **Привязка аккаунтов:** игрок связывает Telegram с тегом своего аккаунта в игре (можно несколько) и видит свои атаки. Есть проверка, что все привязанные игроки состоят в группе.
- **Подписки и уведомления:** фоновый поток раз в минуту опрашивает API и присылает уведомления о старте войны, за 3 часа до конца и по итогам (кто не провёл атаки).
- **Чистый чат:** меню на инлайн-кнопках, служебные сообщения удаляются по таймеру, неактивные меню закрываются сами.

## Как устроено

- Python, Telegram Bot API напрямую через `requests` (long polling `getUpdates`), без фреймворков.
- SQLite для привязок и подписок, с миграцией старой схемы (одна привязка на пользователя → несколько).
- Два фоновых потока (`threading`): уведомления о войне и автоудаление сообщений.
- Все секреты берутся из переменных окружения (`.env`).

## Запуск

Нужен Python 3.10+.

```bash
python -m venv .venv
source .venv/bin/activate        # Windows: .venv\Scripts\activate
pip install -r requirements.txt
cp .env.example .env             # заполнить токены
python bot.py
```

Переменные описаны в `.env.example`:

| Переменная | Обязательна | Что это |
|------------|-------------|---------|
| `TELEGRAM_BOT_TOKEN` | да | токен бота от @BotFather |
| `COC_API_TOKEN` | для команд войны | ключ с developer.clashofclans.com, привязан к IP сервера |
| `CLAN_TAG` | для команд войны | тег клана, например `#ABC123` |
| `GROUP_CHAT_ID` | нет | ID группы клана для общих уведомлений |
| `GROUP_THREAD_ID` | нет | ID темы в группе, если бот должен работать только в ней |

База `links.db` создаётся автоматически при первом запуске. `debug.py` — отладочный скрипт, печатает ответ API по текущей войне.

## Команды

`/start`, `/menu` — главное меню · `/warstatus`, `/warstart`, `/warend`, `/warleft`, `/warcurrent` — война · `/missed` — кто не атаковал · `/link <тег>`, `/mytag`, `/myattacks` — аккаунты · `/checklinks` — проверка привязок
